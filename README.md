# Essenwa

Aplikasi penyimpanan berkas dan catatan teks (PWA). Login saja, tanpa fitur daftar. Akun dibuat di Firebase Console.

## Struktur
- `index.html` – seluruh aplikasi (CSS + JS di dalam satu file)
- `manifest.json`, `service-worker.js` – PWA
- `icons/` – ikon aplikasi
- `.nojekyll` – agar GitHub Pages menyajikan file apa adanya

## Firebase
Project: `essenwa-7f03e`. Aktifkan Authentication (Email/Password), Firestore Database, dan Storage. Tempel rules dari panduan ke tab Rules masing-masing.
